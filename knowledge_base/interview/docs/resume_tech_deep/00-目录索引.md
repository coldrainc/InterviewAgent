## 深挖重点

推荐按这条顺序复习：

```text
ArkUI / LiveView
  -> 直播端侧复杂 UI 和状态治理

Hybrid / 微前端
  -> 移动端动态化、容器、JSBridge 和业务上下文注入

WebRuntime / Sandbox
  -> 插件运行时、隔离执行、权限和故障隔离

Electron + NestJS
  -> 桌面工作台、本地系统能力、后端任务编排和工程化

AI Agent / RAG / MCP
  -> Agent 状态机、工具协议、知识检索、评测和安全边界
```

每份文档都已经补充到可被深挖的粒度：

- **ArkUI / LiveView**：重点看 ArkUI 渲染链路、状态模型、Tetris / Element 分层、高频消息刷新治理、FrameNode / NodeController 选型和内存泄漏排查。
- **Hybrid / 微前端**：重点看容器控制面、离线包、容器池、JSBridge 协议化、安全校验、微前端隔离、端前状态一致性和可观测性。
- **WebRuntime / Sandbox**：重点看 Runtime 控制面 / 执行面、插件 Manifest、权限模型、资源配额、Module Loader、Sandbox 通信协议和故障隔离。
- **Electron + NestJS**：重点看 Electron 三进程边界、preload / contextBridge、IPC 协议化、CLI / 本地服务调用、NestJS DI、长任务队列和桌面端发布升级。
- **AI Agent / RAG / MCP**：重点看 Agent 状态机、Planner / Executor 分层、Tool Schema、MCP Tool / Resource / Prompt 边界、RAG chunking、Hybrid Search、rerank、防幻觉、Memory 和 Trace 评测。

## 面试推荐讲法

简历里的技术栈可以收敛成三条能力线：

- **跨端客户端能力**：React Native、Lynx、KMP、ArkUI、Hybrid。
- **复杂系统工程能力**：WebRuntime、Sandbox、Electron、NestJS、微前端、工程化。
- **AI 工程化能力**：Agent、MCP、TCC、RAG、工具调用、评测和沙箱执行。

一句话概括：

> 我的经历不是单一客户端开发，而是从移动端跨端、直播复杂业务，到 WebRuntime/Sandbox 和 AI Agent 平台都有落地经验。我的优势是能在复杂业务里拆边界、做平台化抽象，并把端侧、前端、后端和 AI 工具链串成可用系统。
